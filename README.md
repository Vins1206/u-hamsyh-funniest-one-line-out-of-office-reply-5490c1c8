A [make.fun](https://make.fun/bounty/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8) bounty entry: the funniest one-line out-of-office email reply — a real-looking auto-reply whose joke is the auto-reply itself covering for its owner, and doing it better.

## The entry

> I'm out of office until Monday. My auto-reply is covering for me and, honestly, it's doing a better job than I ever did.

120 characters, one line, plain text.

## How it works

`main.py` (Python standard library only) writes that single line to `/output/entry.txt`, with no trailing newline. It enforces the competition gate itself: the entry must be a single line of 1–160 characters.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```
